# 清理工具讲解 · 从流氓软件到系统瘦身

> 这套工具是拿来给「被捆绑软件塞满、开机慢、浏览器被劫持」的电脑做清理的，
> 目标很明确：**不重装系统**，把流氓软件、弹窗、主页劫持、开机自启、残留垃圾清干净，
> 并且让这台电脑以后不容易再中招。
>
> 下面按「干什么活」把工具分组讲清楚。不追求把所有功能列全，只讲**清理场景下真正会用到的那部分**。

![书架背景](https://img2024.cnblogs.com/blog/3838669/202610/3838669-20261018124809216-1086831633.jpg)

---

## 一、先看这个：清理的正确顺序

不懂技术也能照着走，**顺序别乱**。乱序的典型后果是：先删了文件，卸载程序就废了，只能手动抠注册表。

| 步骤 | 做什么 | 用什么 |
|---|---|---|
| 0 | 建系统还原点（出事能回滚） | 系统自带 `sysdm.cpl` |
| 1 | 扫一遍机器上到底有哪些流氓软件 | **SoftCnKiller** |
| 2 | 卸载主程序 | **HiBit Uninstaller** / Geek / BCUninstaller |
| 3 | 清残留（AppData / 注册表 / 服务） | **HiBit** + 黑名单数据 |
| 4 | 查开机自启（最容易漏的一步） | **Autoruns** |
| 5 | 修浏览器（主页、搜索、快捷方式参数） | 手动 + 排查脚本 |
| 6 | 装防御，防止复发 | **火绒** + AdwCleaner |

> **断网再卸载。** 很多卸载程序会联网汇报卸载行为，甚至顺手再装回来。

## 二、卸载类：把主程序干掉

### HiBit Uninstaller（主力，90% 的情况用它）

便携版，解压即用，不用安装。真正让它成为主力的是这几个功能：

- **强制卸载**：对付「卸载程序自己坏了」「控制面板里根本没有」的软件
- **安装监视器**：先开监视器再装软件，装完能看到它到底往注册表和硬盘里丢了什么 —— 排查「装 A 送 B」的神器
- **残留扫描**：卸载完自动扫注册表项、文件目录、服务，可勾选清理
- **右键菜单管理**：流氓软件最爱往右键菜单塞「用 XX 解压」「上传到 XX」

用的时候注意一点：它扫出来的残留**不要全选删**，勾选前看一眼路径，
`C:\Windows\System32` 下的东西基本都不该动。

### Geek Uninstaller（应急 / 低配机）

单文件、体积小、启动快，卸载后自动扫残留。功能比 HiBit 少一大截，
但拿来在别人的旧电脑上快速处理一两个软件足够。装在 U 盘里随身带也方便。

### BCUninstaller（要一次卸几十个时用）

批量选中、静默卸载，最有价值的是它的**评分机制**：
按「是否有 Microsoft 数字签名」「有没有安装路径」「体积大小」给每个软件打分，
垃圾软件会直接排到最前面，一眼就能看出来该删谁。

需要 .NET 8 运行时；目标是 .NET 8 版本，Win10 1809 以上一般能直接跑。

### SoftCnKiller（清理前必跑，定位阶段）

它干的事和上面三个不一样 —— **不是卸载器，是探测器**。

基于一份官方维护的黑名单（275 个流氓软件安装目录名 + 166 家流氓公司数字签名），
把散落在 `AppData`、`ProgramData`、`Temp` 里的东西一个个揪出来，
**包括那些压根没在「程序和功能」里登记、你根本不知道它存在的**。

> 这个包里的 `SoftCnKiller-2.88.zip` 解压密码是 **`0000`**。
> 程序本体作者只发蓝奏云和 CSDN，没有 GitHub Release，所以这里只能附上压缩包和它用的**黑名单数据**。

## 三、系统清理与优化

### Dism++

国产开源，做的是**系统层面的瘦身**，而不是「删垃圾文件」这种表面活：

- **空间回收**：清理 WinSxS 组件存储、更新残留、旧版驱动、系统还原点 —— 这一项经常能腾出好几个 GB
- **启动项管理**：和任务管理器看到的不是一套，能管到更底层
- **Appx 管理**：卸载预装的 UWP 应用（那些「天气」「资讯」）

比 CCleaner 干净得多，而且不开会员、不装全家桶。

> 空间回收里「WinSxS 组件存储」清理**不可逆**，清完就无法卸载已安装的更新了。
> 做之前一定有还原点。

### BleachBit

开源清理工具，强项是**浏览器缓存与隐私痕迹**：各浏览器缓存、Cookie、历史、
以及各种软件的日志和临时文件。

它有个特性要留意：默认是「预览」模式，勾选后要先点「预览」看会删什么，
确认没问题再点「删除」。想彻底擦除空闲空间可以勾 `Free disk space`，但会跑很久。

## 四、启动项与进程排查

清理完还卡、还弹窗，问题基本都在这一层。

### Autoruns（最强启动项排查）

任务管理器只显示一部分自启项，Autoruns 显示的是**全部**：
注册表 Run/RunOnce、启动文件夹、计划任务、服务、驱动、Winlogon、AppInit_DLLs、
浏览器插件、Winsock LSP、甚至资源管理器扩展。

**正确用法**：

1. 用管理员身份运行 `Autoruns64.exe`
2. `Options → Hide Microsoft Entries` 隐藏微软签名项（这一步能让列表短 90%）
3. `Options → Verify Code Signatures` 校验签名，没签名的会标红
4. 剩下的红黄条目，逐条看 `Image Path` 和 `Publisher`，可疑的**先取消勾选**而不是删除

> ⚠️ **取消勾选 ≠ 删除**。取消勾选只是禁用，随时能勾回来；
> 直接删注册表项出问题时不好恢复。先禁用，观察几天没问题再说。

命令行导出全量列表（方便存档对比）：

```powershell
autorunsc64.exe -a * -h -s -c -accepteula > autoruns.csv
```

### Process Explorer（任务管理器的完全体）

比任务管理器强的地方：

- **进程树**：看清谁启动了谁，流氓软件常挂在 explorer.exe 或某个「服务宿主」下面
- **句柄 / DLL**：`Ctrl+F` 搜一个文件名，直接告诉你**哪个进程正占用着它**（删不掉的文件全靠这招）
- **数字签名**：进程属性里能看签名和公司，伪造的签名一眼看穿
- **VirusTotal 联动**：`Options → VirusTotal.com → Check VirusTotal.com`，直接把进程哈希丢上去查

### WizTree

图形化的磁盘占用分析，直接读 NTFS 的 MFT 表，几秒钟扫完整个盘，
用**树状图**显示哪个目录、哪个文件最占地方。

清理场景里它解决的是「C 盘满了但不知道被什么吃了」——
扫一遍，通常能发现某个流氓软件的缓存目录占了十几 GB。

### ContextMenuManager

专管右键菜单。流氓软件往右键塞的「用 XX 打开」「上传到 XX」「XX 压缩」
在这里能一次性关掉，也能管「新建」菜单和发送到菜单。

### 排查脚本（附带）

包里还有三个 PowerShell 脚本，**全部只读**，只输出报告不改任何设置：

- `扫描-AppData流氓目录.ps1` —— 对照 275 条黑名单扫 AppData / ProgramData / Temp
- `检查-启动项与计划任务.ps1` —— 导出全部自启点并标注签名
- `检查-浏览器劫持项.ps1` —— 主页、搜索引擎、代理、hosts、快捷方式参数

## 五、安全与拦截

### 火绒安全

国产免费杀软里最干净的一个：**无广告、无捆绑、可卸载**。

清理场景里它有三个用处：
1. **弹窗拦截** —— 独立功能，能拦掉没装杀软时那些推广弹窗
2. **浏览器保护** —— 锁住主页和搜索引擎，防止改回去
3. **HIPS 自定义规则** —— 能拦「装 A 的时候顺手装 B」这个行为本身

### 卡巴斯基 免费版 / 标准版

两个安装包都在包里，注意区分：

| 版本 | 定位 |
|---|---|
| **免费版** | 基础防护，免费长期用 |
| **标准版** | 功能比免费版更全（含防火墙、更完整的防护项） |

> 标准版的安装包文件名是 `startup.exe`，容易被误认成别的东西 —— 它确实是卡巴斯基安装包，
> 内嵌版本号 21.26.4.406，原始文件名 `Setup.exe`。

### AdwCleaner（先跑它，风险最低）

Malwarebytes 出的广告软件专杀，干的是**浏览器劫持**这一路：
主页锁定、搜索引擎被改、工具栏、流氓扩展、计划任务里的推广项。

它最适合**最先跑**，理由是：**扫描快、默认不改系统设置、每次清理都可一键还原**。
先跑一轮看看能扫出什么，心里有数了再动手做其它清理。

## 六、多线程下载

### aria2 / Motrix

这两个是同一个东西的两张脸：Motrix 是基于 aria2 的图形界面。

装在清理后的机器上主要是解决「用浏览器下载大文件慢且容易断」，
另外 aria2 支持断点续传和多源，对付国内下载站的限速有点用。

> 顺带一提：下载站那个巨大的「高速下载」按钮基本都捆绑了安装器，
> 真正该点的是旁边小字「普通下载」或「本地下载」。

## 七、Sysinternals Suite 详解

这一套是**微软官方**出的系统工具合集（作者 Mark Russinovich，后来被微软收购）。
压缩包解压后是 **164 个文件、192 MB**，一个安装程序都没有 —— 全部绿色，解压到哪都能跑。

> 名字带 `64` 的是 64 位版本，现在的系统一律用 64 位版；
> 命令行版本（如 `autorunsc64.exe`、`tcpvcon64.exe`）比图形版多一个 `c`，适合脚本化。

这么多工具不需要全学。下面按**清理场景**把真正用得上的挑出来。

### 7.1 进程排查三件套

| 工具 | 干什么 | 清理时怎么用 |
|---|---|---|
| `procexp64.exe` | Process Explorer | `Ctrl+F` 搜文件名找占用进程；开启 VirusTotal 查进程哈希 |
| `Procmon64.exe` | Process Monitor | 实时记录文件/注册表/网络操作，**定位流氓软件到底在写什么** |
| `procdump64.exe` | 进程转储 | 某进程崩溃/可疑时导出内存给分析用 |

**Process Monitor 是排查的神器，但也是新手劝退器** —— 它默认会把所有操作全录下来，
几秒钟就是几十万条。正确姿势：

1. 先按 `Ctrl+E` 停止捕获
2. `Ctrl+L` 打开过滤器，加上你要盯的进程名或路径
3. 再 `Ctrl+E` 开始捕获，只操作那一个动作

比如想抓「某软件安装时到底写了哪些注册表」，就过滤 `Process Name is 安装器.exe`，
然后跑一次安装，结束后 `Ctrl+F` 搜可疑公司名。

### 7.2 自启与持久化

| 工具 | 说明 |
|---|---|
| `Autoruns64.exe` | 图形版，前面讲过，**最全面的自启点查看器** |
| `autorunsc64.exe` | 命令行版，适合导出 CSV 存档后对比 |
| `PsExec64.exe` | 远程/提权执行命令 |
| `Sysmon64.exe` | 系统监控服务，记录进程创建/网络连接，需要先安装 |

> ⚠️ **`PsExec64.exe` 和 `Sysmon64.exe` 会被几乎所有杀软重点告警** —— 这是正常的，
> 因为真实攻击者也爱用它们。自己电脑上被杀了不是误报问题，是这两个工具本身敏感。
> 清理别人的电脑时**不要随手运行前者**，容易引起误会。

### 7.3 网络与端口

| 工具 | 干什么 |
|---|---|
| `tcpview64.exe` | 图形化实时显示所有 TCP/UDP 连接，哪个进程连了哪个 IP 一目了然 |
| `tcpvcon64.exe` | 命令行版，可 `-a` 输出全部连接 |
| `whois64.exe` | 查 IP / 域名归属，配合上面的 IP 判断是不是在跟推广服务器通信 |
| `pipelist64.exe` | 列出命名管道，排查可疑的进程间通信 |

排查「有没有偷偷联网」的标准流程：`tcpview64.exe` 看有没有陌生 IP 的 ESTABLISHED 连接
→ 右键进程看路径和签名 → 可疑的话用 `whois64.exe` 查那个 IP 归属。

### 7.4 文件、句柄与磁盘

| 工具 | 干什么 | 典型用法 |
|---|---|---|
| `handle64.exe` | 查谁占用了某个文件/目录 | `handle64.exe -a -p <PID>` |
| `listdlls64.exe` | 列出进程加载的所有 DLL | `listdlls64.exe -u <PID>` 只看**未签名**的 |
| `du64.exe` | 命令行磁盘占用统计 | `du64.exe -v -l 1 C:\Users` |
| `streams64.exe` | 查看 NTFS 备用数据流（ADS） | `streams64.exe -s <目录>` |
| `junction64.exe` | 查看/管理目录联接（符号链接） | 流氓软件常用联接把文件藏到别处 |
| `sigcheck64.exe` | **批量校验数字签名** | `sigcheck64.exe -a -e -s -h <目录>` |
| `strings64.exe` | 从二进制里提取可读字符串 | `strings64.exe -n 8 <文件>` |

**`sigcheck` 是清理时最被低估的工具。** 把可疑目录整个扫一遍，输出里带
`Unsigned` 或签名公司是没听过的小公司的，基本就是目标：

```powershell
# 扫描某个目录下所有 exe/dll 的签名与版本信息，输出 CSV
sigcheck64.exe -a -e -s -h -c "C:\Users\你的用户名\AppData\Roaming" > sigcheck.csv
```

### 7.5 系统信息与资源

| 工具 | 干什么 |
|---|---|
| `RAMMap64.exe` | 物理内存详细分布（分页缓冲、驱动占用、缓存），排查「内存莫名被吃」 |
| `vmmap64.exe` | 单个进程的虚拟内存分布 |
| `pslist64.exe` / `psinfo64.exe` | 命令行列进程 / 进程详情（可加 `-s` 看线程） |
| `pskill64.exe` | 强行结束进程（任务管理器杀不掉时用） |
| `logonsessions64.exe` | 当前登录会话列表 |
| `psloggedon64.exe` | 谁登录在这台机器上（本地/远程） |
| `psfile64.exe` | 查看被共享打开的文件 |
| `Coreinfo64.exe` | CPU 特性、缓存、NUMA 拓扑 |
| `zoomIt64.exe` | 屏幕放大/标注工具（远程指导别人操作时非常好用） |

### 7.6 彻底删除与环境检查

| 工具 | 干什么 | 风险 |
|---|---|---|
| `sdelete64.exe` | 安全擦除，`-z` 可清零空闲空间 | ⚠️ **把空闲空间写零，机械盘上可能跑几个小时，期间不要中断** |
| `accesschk64.exe` | 检查文件/注册表/服务的权限 | 只读，安全 |
| `accessenum.exe` | 枚举目录和注册表权限 | 只读，安全 |
| `Autoruns` 里的 `Verify` | 校验自启项签名 | 只读，安全 |

### 7.7 一个具体的排查例子

假设「开机后有个不明进程在跑，不知道哪来的」，用 Sysinternals 的排查链路：

1. `tcpview64.exe` —— 看它有没有外联，连到哪个 IP
2. `whois64.exe <那个IP>` —— 查归属，判断是不是推广服务器
3. `procexp64.exe` —— `Ctrl+F` 搜进程名，看它的路径、命令行、数字签名
4. `autorunsc64.exe -a * -h -s` —— 导出全部自启点，搜这个进程名，找到是谁拉起来的
5. `sigcheck64.exe` —— 校验它的签名，以及同目录其他文件
6. `handle64.exe -a -p <PID>` —— 看它在读写哪些文件

这套流程走下来，一个不明进程的**来源、行为、关联文件**基本就都清楚了。

### 7.8 使用注意

- **整包解压后再运行**，单独拷一个 exe 出来经常缺依赖
- 首次运行会弹 EULA，加 `-accepteula` 参数可直接接受（命令行工具）
- **`PsExec` / `Sysmon` / `sdelete` 这三个不要对别人的电脑随手用**，前两个会被杀软告警，最后一个是破坏性的
- Sysinternals 全部工具都是**只读**的多、写操作的少，日常排查放心用

## 八、三条原则

**1. 先备份，再动手。**
清理注册表和 AppData 是有风险的。动手前一定建系统还原点，
或者用 HiBit 的「备份」功能导出注册表项，重要数据先拷出来。

**2. 判断「是不是流氓软件」，看行为不看名字。**
满足下面任意两条，基本可以判定：

- 没经过你同意就装上了，或者装 A 时「顺手」装上的
- 卸载后在 AppData / ProgramData / 注册表里留一堆东西，或者根本卸不掉
- 开机自启 + 弹窗广告
- 数字签名是一家查不到的小公司，或者压根没签名
- 浏览器主页/搜索引擎被改了，快捷方式被加了参数

**3. 卸载顺序：先断网 → 再卸载 → 最后清残留。**
断网能防止卸载程序联网汇报，也能防止它顺手再装回来。

## 九、风险提示

- 这套流程用于**清理你自己或已获得明确授权的电脑**。给别人清之前先当面确认清单，
  尤其是**公司办公软件、财务软件、行业专用软件** —— 这些经常「长得很像流氓软件」
  （自启、弹窗、写注册表），但删了会出大事。
- 清理注册表前务必有还原点。包里的三个检查脚本**只扫描不删除**，
  删除动作都需要你人工确认。
- 数字签名黑名单的含义是「这家公司出过流氓软件」，
  **不等于该公司所有产品都是流氓软件**，需要结合行为判断。
- 空间回收（Dism++）、安全擦除（sdelete）、PsExec 这些不可逆或敏感的操作，
  看清楚再点。
